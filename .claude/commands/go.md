Plan 파일에서 다음 미완료 테스트를 찾아 TDD 방식으로 구현합니다.

Plan 파일 경로: $ARGUMENTS

없으면 사용자에게 plan 파일 경로를 물어봐주세요. (예: docs/plans/schedule-domain-plan.md)

## 진행 순서
1. Plan 파일을 읽고 첫 번째 `- [ ]` (미완료) 항목을 찾습니다
2. 해당 테스트를 작성합니다 (Red)
3. 테스트가 실패하는지 확인합니다
4. 테스트를 통과하는 최소한의 코드를 구현합니다 (Green)
5. 필요시 리팩토링합니다
6. 모든 테스트가 통과하면 plan 파일의 해당 항목을 `- [x]`로 변경합니다
7. 결과를 보고합니다

## 주의사항
- TDD 원칙: 테스트 먼저, 최소 구현, 리팩토링
- 한 번에 하나의 테스트만 진행
- CLAUDE.md의 CQRS 패턴과 REFERENCE CODE를 참고하여 일관된 스타일 유지
