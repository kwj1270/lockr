도메인 컨텍스트를 읽고 요약합니다.

도메인: $ARGUMENTS

## 사용 가능한 도메인
- `auth` → docs/domains/auth-context.md
- `users` → docs/domains/users-context.md
- `club` → docs/domains/club-context.md
- `notification` → docs/domains/notification-context.md
- `home` → docs/domains/home-context.md
- `all` → 모든 도메인 개요 (docs/domains/README.md)

## 출력 내용
1. Aggregate Root 구조
2. 주요 Entity/Value Object
3. 비즈니스 규칙
4. 도메인 이벤트
5. 다른 도메인과의 관계

인자가 없으면 전체 도메인 구조 개요(README.md)를 보여줍니다.
